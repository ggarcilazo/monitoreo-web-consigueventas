# Monitoreo Web ConsigueVentas

Sistema web de diagnóstico y monitoreo de sitios web para optimizar el
mantenimiento y la captación de clientes en una agencia de marketing digital.

## Estado del proyecto
🚧 En desarrollo

## Módulos
- Monitoreo periódico (disponibilidad, SSL, velocidad)
- Auditoría a demanda con captación de leads
- Alertas por Telegram
- Panel web (dashboard)

## Stack
FastAPI · Supabase (PostgreSQL) · Python · GitHub Actions · Docker ·
Cloudflare Pages
